Instituição / Contexto

O CISEB é o espaço voltado para a inovação, desenvolvimento de tecnologias educacionais e formação. O projeto de leitura interativa por voz nasce como uma solução para impulsionar o aprendizado e o monitoramento de desempenho dos estudantes.
